# StockFlow Microcopy Sheet

Exact phrasing and messages for all screens (Doc 11.6).

## Button Verbs
- Save batch
- Start sale
- Checkout
- Confirm payment
- Write off
- Register product
- Void last sale
*(Avoid generic "OK" or "Submit")*

## Status & Alert Labels
- `Expires today` (0 days left)
- `Expires in N days` (Red / Amber)
- `Expired. Remove from shelf` (< 0 days)
- `Low stock`
- `Older stock exists: Place new delivery BEHIND existing stock on shelves`

## Money & Date Formatting
- Currency: `PHP 1,250.00`
- Date: `12 Nov 2026`
